# Practice Set — 20 Problems

No tags, no source, no difficulty markers. The core of each problem is one of:
two pointers, sliding window, 1D prefix sums, or 1D difference arrays. Earlier
techniques (sorting, binary search, STL, basic math) may appear as helpers, but
the central idea is always one of those four. Figure out which.

All ranges in input are **1-indexed and inclusive** unless stated otherwise.

---

## 1. Budget Run

You are given `n` positive integers and a budget `K`. Find the length of the
longest contiguous subarray whose elements sum to at most `K`.

- **Input:** first line `n` and `K`; second line `n` integers.
- **Output:** a single integer — the maximum length (0 if every single element already exceeds `K`).
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `1 ≤ a_i ≤ 10^9`, `1 ≤ K ≤ 10^18`.

```
Input
5 7
2 1 5 1 3
Output
3
```

## 2. Garden Watering

There are `n` plants in a row, each starting with 0 units of water. You perform
`m` operations; each operation `l r x` pours `x` units of water on every plant
from position `l` to `r`. After all operations, print every plant's water level.

- **Input:** first line `n` and `m`; then `m` lines, each `l r x`.
- **Output:** `n` integers — the final water level of each plant.
- **Constraints:** `1 ≤ n, m ≤ 2·10^5`, `1 ≤ l ≤ r ≤ n`, `1 ≤ x ≤ 10^9`.

```
Input
5 2
1 3 2
2 5 1
Output
2 3 3 1 1
```

## 3. Divisible Windows

Given an array of `n` integers and a modulus `m`, count the number of contiguous
subarrays whose sum is divisible by `m`.

- **Input:** first line `n` and `m`; second line `n` integers.
- **Output:** a single integer — the count.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `2 ≤ m ≤ 10^5`, `|a_i| ≤ 10^9`.

```
Input
4 3
1 2 3 3
Output
6
```

## 4. Boat Pairs

There are `n` people with given weights. Each boat carries at most 2 people, and
the combined weight on a boat must not exceed `L`. Every person must be carried.
Find the minimum number of boats needed.

- **Input:** first line `n` and `L`; second line `n` integers (the weights).
- **Output:** a single integer — the minimum number of boats.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `1 ≤ weight_i ≤ L ≤ 10^9`.

```
Input
4 6
3 5 3 4
Output
3
```

## 5. Variety Limit

Given a string of `n` lowercase letters and an integer `K`, find the length of
the longest contiguous substring that contains at most `K` distinct letters.

- **Input:** first line `n` and `K`; second line the string.
- **Output:** a single integer — the maximum length.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `1 ≤ K ≤ 26`.

```
Input
6 2
abaccc
Output
4
```

## 7. Bus Passengers

A bus route has `n` stops. There are `m` passengers; passenger `i` boards at stop
`a_i` and gets off at stop `b_i` (`a_i < b_i`), occupying one seat on every
segment between consecutive stops from `a_i` up to `b_i` (segments
`a_i, a_i+1, …, b_i − 1`). The bus has `C` seats. Determine whether the bus is
ever over capacity.

- **Input:** first line `n`, `m`, `C`; then `m` lines, each `a_i b_i`.
- **Output:** `YES` if the seat count exceeds `C` on some segment, otherwise `NO`.
- **Constraints:** `2 ≤ n ≤ 2·10^5`, `1 ≤ m ≤ 2·10^5`, `1 ≤ a_i < b_i ≤ n`, `1 ≤ C ≤ 2·10^5`.

```
Input
5 3 2
1 4
2 5
1 3
Output
YES
```

## 8. Cheap Pairs

Given a **sorted** array of `n` integers and a value `X`, count the number of
unordered pairs of indices `(i, j)` with `i < j` and `a_i + a_j < X`.

- **Input:** first line `n` and `X`; second line `n` integers in non-decreasing order.
- **Output:** a single integer — the number of pairs.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `|a_i| ≤ 10^9`, `|X| ≤ 10^10`.

```
Input
4 5
1 2 3 4
Output
2
```

## 9. Best k-Window

Given an array of `n` integers and an integer `k`, find the maximum possible sum
of any contiguous subarray of length exactly `k`.

- **Input:** first line `n` and `k`; second line `n` integers.
- **Output:** a single integer — the maximum sum.
- **Constraints:** `1 ≤ k ≤ n ≤ 2·10^5`, `|a_i| ≤ 10^9`.

```
Input
5 2
1 -2 3 4 -1
Output
7
```

## 10. Flip to Win

Given a binary array of `n` elements (each 0 or 1) and an integer `K`, find the
maximum number of consecutive 1s you can obtain if you may change at most `K` of
the zeros into ones.

- **Input:** first line `n` and `K`; second line `n` values (each 0 or 1).
- **Output:** a single integer — the maximum run of 1s achievable.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `0 ≤ K ≤ n`.

```
Input
6 1
1 0 1 1 0 1
Output
4
```

## 11. Meeting Rooms Peak

There are `n` meetings; meeting `i` occupies the integer time interval
`[s_i, e_i]` inclusive. At any integer moment, the number of active meetings is
how many intervals contain that moment. Find the maximum number of meetings
active at the same moment.

- **Input:** first line `n`; then `n` lines, each `s_i e_i`.
- **Output:** a single integer — the maximum concurrent count.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `1 ≤ s_i ≤ e_i ≤ 10^6`.

```
Input
3
1 4
2 5
3 6
Output
3
```

## 12. Two of a Kind

Given a sorted array of `n` distinct integers and a value `T`, determine whether
there exist two different elements that sum to exactly `T`.

- **Input:** first line `n` and `T`; second line `n` distinct integers in increasing order.
- **Output:** `YES` if such a pair exists, otherwise `NO`.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `|a_i| ≤ 10^9`, `|T| ≤ 10^10`.

```
Input
4 11
1 3 5 8
Output
YES
```

## 13. Quick Quota

Given `n` positive integers and a target `S`, find the length of the shortest
contiguous subarray whose sum is at least `S`. If no such subarray exists, output 0.

- **Input:** first line `n` and `S`; second line `n` integers.
- **Output:** a single integer — the shortest valid length, or 0.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `1 ≤ a_i ≤ 10^9`, `1 ≤ S ≤ 10^18`.

```
Input
6 7
2 3 1 2 4 3
Output
2
```

## 14. More A than B

You are given a string of `n` characters, each either `A` or `B`, and `q`
queries. Each query gives `l` and `r`; report whether the substring from `l` to
`r` contains strictly more `A`s than `B`s.

- **Input:** first line `n` and `q`; second line the string; then `q` lines, each `l r`.
- **Output:** for each query, `YES` or `NO` on its own line.
- **Constraints:** `1 ≤ n, q ≤ 2·10^5`, `1 ≤ l ≤ r ≤ n`.

```
Input
6 2
AABBAB
1 2
3 6
Output
YES
NO
```

## 15. Shared Scores

Two sorted arrays `A` (size `n`) and `B` (size `m`) each contain distinct
integers. Count how many integers are present in both arrays.

- **Input:** first line `n` and `m`; second line `n` integers (sorted); third line `m` integers (sorted).
- **Output:** a single integer — the count of common values.
- **Constraints:** `1 ≤ n, m ≤ 2·10^5`, `|value| ≤ 10^9`.

```
Input
4 4
1 3 5 7
2 3 5 9
Output
2
```

## 16. Stadium Lights

A stadium has `n` lights in a row, all off. You receive `m` commands; command
`l r` flips (on↔off) every light from `l` to `r`. After all commands, print how
many lights are on.

- **Input:** first line `n` and `m`; then `m` lines, each `l r`.
- **Output:** a single integer — the number of lights that are on.
- **Constraints:** `1 ≤ n, m ≤ 2·10^5`, `1 ≤ l ≤ r ≤ n`.

```
Input
5 2
1 3
2 4
Output
2
```

## 17. Fair Split Point

Given an array of `n` integers, count the number of positions `i`
(`1 ≤ i ≤ n − 1`) such that the sum of the first `i` elements equals the sum of

- **Input:** first line `n`; second line `n` integers.
- **Output:** a single integer — the number of such split positions.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `|a_i| ≤ 10^9`.

```
Input
4
1 0 0 1
Output
3
```

## 19. Exact Difference

Given an array of `n` integers and a value `D ≥ 0`, count the number of unordered
pairs of indices `(i, j)`, `i < j`, with `|a_i − a_j| = D`.

- **Input:** first line `n` and `D`; second line `n` integers.
- **Output:** a single integer — the number of pairs.
- **Constraints:** `1 ≤ n ≤ 2·10^5`, `|a_i| ≤ 10^9`, `0 ≤ D ≤ 10^9`.

```
Input
5 2
1 5 3 4 2
Output
3
```

## 20. Painted Fence

A fence has `n` panels, all initially unpainted. `m` painters each paint a
contiguous range `[l, r]`. After everyone finishes, count how many panels remain
unpainted (covered by zero painters).

- **Input:** first line `n` and `m`; then `m` lines, each `l r`.
- **Output:** a single integer — the number of unpainted panels.
- **Constraints:** `1 ≤ n, m ≤ 2·10^5`, `1 ≤ l ≤ r ≤ n`.

```
Input
5 2
1 2
4 5
Output
1
```
