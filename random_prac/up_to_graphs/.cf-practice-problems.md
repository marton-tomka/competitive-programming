# 10 CF-style practice problems

Original problems, varying difficulty, algorithms not labeled. Each is solvable
with something from `kots-templates.md`, sometimes plus an observation on top.

---

### Problem 1 — Frontier Settlements

**Time limit:** 2 seconds **Memory limit:** 256 MB

There are `n` settlements, numbered `1` to `n`, on a frontier planet, with no
roads between them yet. Over `m` days, one of two events happens:

- `1 u v` — a new two-way road is completed between `u` and `v`. (It's possible
  `u` and `v` were already connected via other roads, in which case the road is
  redundant but still gets built.)
- `2 u v` — the council wants to know whether `u` and `v` are currently
  connected by roads, directly or indirectly.

After all `m` events have been processed, the council also wants a final
summary: how many connected components remain, and the size of the largest one.

**Input**

Line 1: two integers `n m` (`1 ≤ n, m ≤ 2·10^5`).
Next `m` lines: one event each, formatted as above (`1 ≤ u, v ≤ n`, `u ≠ v`).

**Output**

For each event of type `2`, in order, print `YES` or `NO` on its own line.
After all events, print one more line with two integers: the number of
connected components, and the size of the largest one.

**Example**

```
input
6 8
1 1 2
1 3 4
2 1 2
2 1 3
1 2 3
2 1 4
1 5 6
2 5 1
```
```
output
YES
NO
YES
NO
2 4
```

### Problem 2 — Two Rival Guilds

**Time limit:** 2 seconds **Memory limit:** 256 MB

There are `n` adventurers and `m` known rivalries. Rivalry `i` is a pair
`(a_i, b_i)` meaning those two adventurers refuse to be in the same guild.
You must split all `n` adventurers between two guilds, **Sun** and **Moon**
(every adventurer assigned to exactly one), such that every rivalry pair ends
up in different guilds.

Determine whether this is possible, and if so, produce one valid assignment.

**Input**

Line 1: two integers `n m` (`1 ≤ n, m ≤ 2·10^5`).
Next `m` lines: two integers `a_i b_i` (`1 ≤ a_i, b_i ≤ n`, `a_i ≠ b_i`).

**Output**

If no valid split exists, print a single line `NO`.
Otherwise print `YES` on the first line, then a line of `n` integers, the
`i`-th being `1` (Sun) or `2` (Moon) for adventurer `i`. Any valid assignment
is accepted.

**Example**

```
input
6 5
1 2
2 3
4 5
5 6
1 6
```
```
output
YES
1 2 1 2 1 2
```

**Note.** Adventurers 1–2–3 and 1–6–5–4 form a tree of rivalries; any proper
2-coloring works, e.g. the one shown.

### Problem 3 — Assembly Line Order

**Time limit:** 2 seconds **Memory limit:** 256 MB

A factory has `n` modules, numbered `1` to `n`, and `m` prerequisite rules.
Rule `(a, b)` means module `a` must be installed strictly before module `b`.

Find an installation order respecting all rules. If several orders are valid,
output the **lexicographically smallest** one (as a sequence of module
numbers). If no valid order exists, print `IMPOSSIBLE`.

**Input**

Line 1: two integers `n m` (`1 ≤ n ≤ 2·10^5`, `0 ≤ m ≤ 4·10^5`).
Next `m` lines: two integers `a b` (`1 ≤ a, b ≤ n`, `a ≠ b`).

**Output**

Either `IMPOSSIBLE`, or `n` integers — the installation order.

**Examples**

```
input
4 4
1 2
1 3
3 4
2 4
```
```
output
1 2 3 4
```

```
input
3 3
1 2
2 3
3 1
```
```
output
IMPOSSIBLE
```

### Problem 4 — Donut World Delivery

**Time limit:** 2 seconds **Memory limit:** 256 MB

A delivery drone operates on a planet shaped like a torus: its map is an
`R × C` grid where moving off the top edge wraps to the bottom edge (same
column), and moving off the left edge wraps to the right edge (same row), and
vice versa. Each cell is either open (`.`) or storm-blocked (`#`). In one move
the drone shifts to an (wrapped) orthogonally adjacent cell, provided that
cell is open.

Given a start cell and a target cell (both guaranteed open), find the minimum
number of moves to reach the target, or `-1` if impossible.

**Input**

Line 1: `R C` (`1 ≤ R, C ≤ 1000`, `R·C ≤ 10^6`).
Next `R` lines: the grid.
Last line: `sr sc tr tc` — 0-indexed start row/col and target row/col.

**Output**

A single integer: the minimum number of moves, or `-1`.

**Example**

```
input
3 3
...
.#.
...
0 0 2 2
```
```
output
2
```

**Note.** `(0,0)` → wrap up → `(2,0)` → wrap left → `(2,2)`, avoiding the
blocked center cell entirely.

### Problem 5 — The Griffin's Flight

**Time limit:** 2 seconds **Memory limit:** 256 MB

A griffin sits on an `R × C` board (0-indexed rows/cols). In one move it jumps
in an L-shape: two squares in one direction and one square perpendicular to
it (the same move pattern as a chess knight). Some squares are blocked and
the griffin may never land on them; it also may never leave the board.

Given a start square and a target square (both open), find the minimum number
of moves for the griffin to reach the target, or `-1` if it can't.

**Input**

Line 1: `R C` (`1 ≤ R, C ≤ 1000`).
Next `R` lines: `C` characters each, `.` for open and `#` for blocked.
Last line: `sr sc tr tc`.

**Output**

A single integer: minimum moves, or `-1`.

**Example**

```
input
8 8
........
........
........
........
........
........
........
........
0 0 7 7
```
```
output
6
```

### Problem 6 — Prime Duel

**Time limit:** 3 seconds **Memory limit:** 256 MB

Two players play a game on a pile of `v` stones. Starting with Player 1, they
alternate turns. On a turn, the current player picks any prime `p` that
divides the current pile size `v`, and removes exactly `p` stones from the
pile. A player who cannot move (no prime divides the current pile size — this
includes `v = 0` and `v = 1`) loses.

Given `q` independent starting values, determine the winner of each game
under optimal play.

**Input**

Line 1: integer `q` (`1 ≤ q ≤ 2·10^5`).
Line 2: `q` integers `v_1, …, v_q` (`1 ≤ v_i ≤ 10^6`).

**Output**

`q` lines, each `First` or `Second`.

**Example**

```
input
5
1 2 4 6 9
```
```
output
Second
First
Second
First
Second
```

**Note.** For `v = 9`, the only move is to subtract `3`, landing on `6` —
which is a winning position for whoever is about to move there. So the
mover at `9` is forced to hand their opponent a win, and loses.

### Problem 7 — Almost Square Fields

**Time limit:** 2 seconds **Memory limit:** 256 MB

A farmer wants to fence a rectangular field of area exactly `A` using whole
numbers of meters for the sides, `l × w = A`, minimizing the total fence
length `2(l + w)`. Equivalently, among all factor pairs of `A`, find the one
whose two factors are as close together as possible.

**Input**

Line 1: integer `q` (`1 ≤ q ≤ 100`).
Next `q` lines: one integer `A` each (`1 ≤ A ≤ 10^12`).

**Output**

For each query, print `l w` with `l ≤ w`, `l·w = A`, and `l + w` minimized.

**Example**

```
input
2
12
1000000000000
```
```
output
3 4
1000000 1000000
```

### Problem 8 — Widest Canopy

**Time limit:** 2 seconds **Memory limit:** 256 MB

`n` trees stand in a row; tree `i` has height `h_i`. You want to stretch a
single rectangular canopy over some contiguous run of trees. The canopy's
height is limited to the shortest tree it covers (it must clear every tree
underneath it). Maximize the canopy's area (width × height, where width is
the number of trees spanned).

**Input**

Line 1: integer `n` (`1 ≤ n ≤ 10^5`).
Line 2: `n` integers `h_i` (`1 ≤ h_i ≤ 10^9`).

**Output**

A single integer: the maximum area.

**Example**

```
input
6
2 1 5 6 2 3
```
```
output
10
```

### Problem 9 — Minimum Energy Hopper

**Time limit:** 2 seconds **Memory limit:** 256 MB

A frog starts on the ground (position `0`, free) and wants to reach position
`n`. Positions `1..n` are platforms; landing on platform `i` costs `c_i`
energy. From any position `i` the frog may jump forward to any position `j`
with `i < j ≤ min(i + k, n)`. Find the minimum total energy to reach position
`n`.

**Input**

Line 1: two integers `n k` (`1 ≤ k ≤ n ≤ 2·10^5`).
Line 2: `n` integers `c_1, …, c_n` (`1 ≤ c_i ≤ 10^9`).

**Output**

A single integer: the minimum total energy.

**Example**

```
input
5 2
3 1 4 1 5
```
```
output
7
```

**Note.** One optimal route lands on platforms `2, 4, 5`, costing `1+1+5 = 7`.

### Problem 10 — Colony Growth Under Radiation

**Time limit:** 2 seconds **Memory limit:** 256 MB

A microbe colony's population follows `p_0 = P`, and for `i ≥ 0`:

```
p_{i+1} = (a * p_i + b) mod M
```

where `M` is guaranteed prime. Given `P, a, b, M`, and a (potentially huge)
`n`, compute `p_n mod M`, across `t` independent scenarios.

**Input**

Line 1: integer `t` (`1 ≤ t ≤ 10^5`).
Next `t` lines: five integers `P a b M n` (`0 ≤ P, a, b < M ≤ 10^9+7`,
`M` prime, `1 ≤ n ≤ 10^18`).

**Output**

`t` lines, each `p_n mod M` for that scenario.

**Example**

```
input
2
1 2 3 1000000007 5
5 1 7 13 4
```
```
output
125
7
```

**Note.** First case, by direct unrolling: `1 → 5 → 13 → 29 → 61 → 125`.
Second case has `a = 1`, a degenerate case worth handling separately.
